# Dataset de regresión visual

`v1` es un dataset versionado y completamente sintético (CC0-1.0). Cada caso representa una
fuente frecuente sin copiar capturas reales ni información privada. Los JSON son respuestas VLM
capturadas/esperadas: las pruebas validan y normalizan estos artefactos locales, no llaman a APIs.

Para una nueva versión, cree otro directorio (`v2`, etc.) en lugar de modificar silenciosamente el
contrato anterior. Revise que no haya nombres de usuario, rutas locales, credenciales ni contenido
procedente de clases o repositorios privados antes de incorporar fixtures.
